# دفتر حساب v8.1

اپ وب آفلاین حسابداری شخصی/کسب‌وکار (درآمد، هزینه، فاکتور، گزارش).

## نسخه اندروید (APK)

فایل نصب‌پذیر debug اینجاست:

**[دانلود APK](android-app/dist/Hesab-v8.1-debug.apk)**

- نام پکیج: `ir.hesab.daftar`
- نسخه: `8.1.0`
- حداقل اندروید: 6.0 (API 23)

روی گوشی، بعد از دانلود، از «منابع ناشناس» اجازه نصب بده و فایل را باز کن.

جزئیات ساخت دوباره: [`android-app/README.md`](android-app/README.md)

دیتابیس **اصلی داخل خود برنامه** است و خودکار ذخیره می‌شود. گزینه‌های JSON/ZIP/ابری فقط پشتیبان اختیاری‌اند.
